# VEK 0.4

VEK / Wekretia is an early-stage 2D RPG prototype built in Godot using GDScript.

The game is set in Wekretia an original dark fantasy world I've been developing for many years through worldbuilding, stories and roleplay.

## Current state

The project is currently in early prototyping.

Implemented so far:

- Basic player controller
- Four-direction movement
- Directional idle and movement animations
- Basic attack state
- Input handling
- Early UI and menu systems

## Tech

- Godot Engine
- GDScript
- 2D
- Aseprite / Krita

## Goal

The long-term goal is to turn Wekretia into a story-driven 2D RPG focused on exploration, combat, worldbuilding, player choices and atmosphere.

For now, the project is mainly a way for me to learn game development, gameplay programming and how to structure larger systems in Godot.
